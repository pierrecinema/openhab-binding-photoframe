# Photo Frame Binding

Turns openHAB into a digital photo frame: pictures from a local folder, a shared Google Drive folder or Dropbox, shown as a full-screen slideshow with transitions, usable as tablet screensaver (Fully Kiosk Browser, WallPanel).

> **Status:** in planning. See the specification (German): [docs/SPEZIFIKATION.md](docs/SPEZIFIKATION.md).

Requires openHAB 5.0 or later.
