Test version of the Photoframe Binding. Requires **openHAB 5.0 or later**.

## Changed
- The ✕ button over openHAB disappears after 6 seconds, so it no longer covers the page. The slideshow still returns by itself after **Return to Slideshow** seconds without touch. With this setting at 0 the button stays, because it is the only way back.

## Fixed
- **Previous** at the start of a new round showed a random picture. It now shows the last picture of the round before.

## Update from 0.0.10
Delete `org.openhab.binding.photoframe-0.0.10.jar` from the `addons` folder and copy `org.openhab.binding.photoframe-0.0.11.jar`.
Reload the slideshow on every screen so the new page is loaded. On the iPad, close the Photoframe web app once (app switcher) and open it again.
