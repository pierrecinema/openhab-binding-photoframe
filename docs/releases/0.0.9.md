Test version of the Photoframe Binding. Requires **openHAB 5.0 or later**.

## New
- **Dashboard widget** `photoframe_card` with live preview, current picture, number of pictures, night mode and buttons for previous, play/pause, next and full screen (English and German). The file is attached to this release.
- **Complete guides**: [README](https://github.com/pierrecinema/openhab-binding-photoframe/blob/main/README.md) with all things, items, channels and examples, and a [German guide](https://github.com/pierrecinema/openhab-binding-photoframe/blob/main/docs/ANLEITUNG.md).
- **Full-screen page in Main UI**: the README shows how to run the slideshow as a page without title bar.

## Fixed
- The slideshow address no longer shows a Docker address when a Docker network uses a 192.168.x.x range.
- Tailscale network addresses are no longer used as slideshow address.
- App addresses such as `intent:` now open from a slideshow embedded in a page instead of showing "This content is blocked".

## Update from 0.0.8
Delete `org.openhab.binding.photoframe-0.0.8.jar` from the `addons` folder and copy `org.openhab.binding.photoframe-0.0.9.jar`.
