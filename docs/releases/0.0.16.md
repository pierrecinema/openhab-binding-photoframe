Test version of the Photoframe Binding. Requires **openHAB 5.0 or later**.

## New
- **Items Below the Weather:** up to 4 items shown below the weather block at the bottom left, e.g. the moon phase. **Overlay Items** stay below the clock at the bottom right.

## Update from 0.0.15
Delete `org.openhab.binding.photoframe-0.0.15.jar` from the `addons` folder and copy `org.openhab.binding.photoframe-0.0.16.jar`.
Reload the slideshow on every screen so the new page is loaded. On the iPad, close the Photoframe web app once (app switcher) and open it again.
