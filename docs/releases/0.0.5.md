Test version of the Photoframe Binding with the first cloud source. Requires **openHAB 5.0 or later**.

## New: Dropbox shared folder link
- New source **Dropbox shared folder link** – no Dropbox account or app needed in openHAB.
- In Dropbox: **Share** on the folder → **Copy link**, paste it into **Shared Link** of the Photoframe thing.
- The binding downloads the folder every 60 minutes (setting *Refresh Interval*, or the *Refresh Now* channel), keeps the pictures of the top level and only converts pictures that changed. Sub folders are ignored.
- Clear messages for wrong links (file instead of folder, link disabled, folder larger than 2 GB).
- Tested with a real shared Dropbox folder.

Note: anyone who knows a shared link can see the pictures. Only put pictures into that folder that may be seen this way. A Dropbox login (private folder) follows in 0.0.6.

## Update from 0.0.4
Delete `org.openhab.binding.photoframe-0.0.4.jar` from the `addons` folder and copy `org.openhab.binding.photoframe-0.0.5.jar`. Existing Photoframe things are kept.
