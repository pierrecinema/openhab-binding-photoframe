Test version of the Photoframe Binding. Requires **openHAB 5.0 or later**. Nothing else has to be installed on the server.

## Changes since 0.0.1
- Name **Photoframe** in all languages (the German UI showed "Bilderrahmen")
- Only working options are offered: the Dropbox bridge and the Google Drive / Dropbox sources are hidden until the versions that implement them

## Included
- **Local folder:** the binding creates `userdata/photoframe/<thing id>` (Docker: `/openhab/userdata/photoframe/<thing id>`) – just put pictures (JPEG, PNG, GIF, BMP) into it
- **Slideshow page** for any browser or as screensaver address in Fully Kiosk Browser / WallPanel: address in the `pageUrl` channel, protected by an access token
- Transitions: fade, slide, wipe, zoom, random – Ken Burns effect – fit with blurred background, black borders, fill or automatic
- Pictures are scaled down and turned according to the phone orientation (EXIF), kept in a cache
- Overlays: clock and date, up to 4 item values, caption from the file name
- Night mode: black, dimmed or black with dimmed clock; `night` channel to force it from rules
- Same picture on all screens; control with the `control` channel (play/pause/next/previous) and rule actions

## Update from 0.0.1
Delete `org.openhab.binding.photoframe-0.0.1.jar` from the `addons` folder and copy the new JAR. An existing Photoframe thing is kept.

## Test
1. Copy `org.openhab.binding.photoframe-0.1.1.jar` into the `addons` folder (Docker: `/openhab/addons`).
1. Add a **Photoframe** thing with source **Local folder**.
1. Put a few pictures into the folder shown in the thing status / properties.
1. Open the address from the **Slideshow Address** channel on a tablet or PC. Tap to switch to full screen.
1. If openHAB runs in Docker without host network, set **openHAB Address** (advanced) to e.g. `http://192.168.1.10:8080`.
