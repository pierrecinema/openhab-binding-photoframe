Test version of the Photoframe Binding. Requires **openHAB 5.0 or later**.

## New
- **Tap opens an app:** the *Tap Address* accepts app addresses, e.g. the openHAB app on Android (`intent:#Intent;…`) or on iOS (`openhab://`). The settings page no longer rejects them.
- **Tap address per screen:** append `&tap=<url-encoded address>` to the slideshow address of a screen. One Photoframe thing can then serve an Android tablet and an iPad, each opening its own app.

## Improved
- The slideshow page also runs in older Android web views and on older iPads (no newer CSS/JS features needed).
- If something goes wrong in the browser, the error is shown on the screen instead of a black page.

## Setup examples
See the README: Fully Kiosk (Android) and Kiosker (iPad), keeping the screen on, opening the openHAB app.

## Update from 0.0.5
Delete `org.openhab.binding.photoframe-0.0.5.jar` from the `addons` folder and copy `org.openhab.binding.photoframe-0.0.6.jar`. Existing Photoframe things are kept.
