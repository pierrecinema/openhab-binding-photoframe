Test version of the Photoframe Binding. Requires **openHAB 5.0 or later**.

## New: weather at the bottom left
- A weather block as counterpart to the clock: icon, large temperature and the weather as text.
- Choose your items in **Weather Icon**, **Weather Temperature** and **Weather Condition**. Every field is optional and any weather binding works.

## Fixed
- Image items in **Overlay Items** are shown as picture instead of "raw type".

## Update from 0.0.14
Delete `org.openhab.binding.photoframe-0.0.14.jar` from the `addons` folder and copy `org.openhab.binding.photoframe-0.0.15.jar`.
Reload the slideshow on every screen so the new page is loaded. On the iPad, close the Photoframe web app once (app switcher) and open it again.
