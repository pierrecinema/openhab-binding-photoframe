Test version of the Photoframe Binding. Requires **openHAB 5.0 or later**. Nothing else has to be installed on the server.

## Changes since 0.0.2
- The default picture folder is now **`userdata/photoframe`** (Docker: `/openhab/userdata/photoframe`) – no sub folder per thing anymore.
  For a second photo frame, enter another folder in its settings, e.g. `/openhab/userdata/photoframe-urlaub`.
- A sub folder created by 0.0.1/0.0.2 (`userdata/photoframe/<thing id>`) is not deleted automatically; move its pictures up one level and delete it.

## Update from 0.0.2
1. Delete `org.openhab.binding.photoframe-0.0.2.jar` from the `addons` folder and copy `org.openhab.binding.photoframe-0.0.3.jar`.
1. The existing Photoframe thing is kept. If its folder setting is empty, it now uses `userdata/photoframe`.

## Test
1. Put a few pictures directly into `userdata/photoframe`.
1. Open the address from the **Slideshow Address** channel on a tablet or PC. Tap to switch to full screen.
1. If openHAB runs in Docker without host network, set **openHAB Address** (advanced) to e.g. `http://192.168.1.10:8080`.
