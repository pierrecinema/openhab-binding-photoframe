Test version of the Photoframe Binding. Requires **openHAB 5.0 or later**.

## Fixed
- After a restart or update the `control` channel could still show PAUSE while the slideshow was running, so the widget showed the wrong button. The channel now always shows the real state.

## Update from 0.0.16
Delete `org.openhab.binding.photoframe-0.0.16.jar` from the `addons` folder and copy `org.openhab.binding.photoframe-0.0.17.jar`.
