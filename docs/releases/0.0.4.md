Test version of the Photoframe Binding with the fixes from the first test. Requires **openHAB 5.0 or later**.

## Fixes
- **Slide transition:** after the first picture the screen could stay black for a whole interval. Transitions now always end with the new picture visible, even if the browser pauses or skips the animation.
- **Slideshow address in Docker:** a Docker network address (e.g. `172.26.0.1`) is no longer used; the binding picks the home network address (e.g. `192.168.1.201`). The **openHAB Address** setting still overrides it.

## Improvements
- **Overlay items:** choose up to 4 items with the item picker instead of typing names. Names typed in 0.0.1–0.0.3 keep working.

## Update from 0.0.3
Delete `org.openhab.binding.photoframe-0.0.3.jar` from the `addons` folder and copy `org.openhab.binding.photoframe-0.0.4.jar`. The Photoframe thing is kept.
If you entered the openHAB Address by hand, you can clear it to test the automatic detection.
