Test version of the Photoframe Binding. Requires **openHAB 5.0 or later**.

## Fixed
- The list in **Page on Tap** stayed empty on openHAB 5.2. It now shows your Main UI pages and sitemaps on every openHAB 5.x.

## Changed
- New introduction in the guides: the slideshow runs inside the openHAB app on Android and iOS and in any browser, no kiosk app needed.

## Update from 0.0.12
Delete `org.openhab.binding.photoframe-0.0.12.jar` from the `addons` folder and copy `org.openhab.binding.photoframe-0.0.13.jar`.

`&tap=` in an address overrides the settings of the thing. If your full-screen page contains `&tap=%2F`, remove it, otherwise a tap keeps opening the start page.
