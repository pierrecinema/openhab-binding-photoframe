Test version of the Photoframe Binding. Requires **openHAB 5.0 or later**.

## New: openHAB on top of the slideshow, automatic return
- If the **Tap Address** is a page of the same openHAB (e.g. `http://192.168.1.10:8080/`), a tap opens it in full screen **on top of the slideshow**.
- While you use openHAB it stays open; after **Return to Slideshow** seconds without touch (advanced setting, default 120) the slideshow comes back by itself. The ✕ button returns at once.
- Works in every browser and as iPad home screen web app – no kiosk app with idle function needed.
- `&return=<seconds>` in the slideshow address sets the idle time for one screen.

App addresses (`intent:…`, `openhab://`, other servers) still open as before.

## Update from 0.0.7
Delete `org.openhab.binding.photoframe-0.0.7.jar` from the `addons` folder and copy `org.openhab.binding.photoframe-0.0.8.jar`.
