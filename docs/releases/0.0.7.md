Test version of the Photoframe Binding. Requires **openHAB 5.0 or later**.

## Fix
- **iPad / iPhone:** clock, date, item values and caption were shown in black instead of white. iOS Safari turned dates and times into links with its own colour; this detection is now switched off and the text is always white.

## Update from 0.0.6
Delete `org.openhab.binding.photoframe-0.0.6.jar` from the `addons` folder and copy `org.openhab.binding.photoframe-0.0.7.jar`.
On the iPad, close the Photoframe web app once (app switcher) and open it again, so the new page is loaded.
